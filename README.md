## 🔗 رابط الموقع
```
https://<YOUR_USERNAME>.github.io/weebeynet/
```

## 📦 الميزات
- 🛍️ سلة تسوق تفاعلية كاملة
- 💳 نظام دفع متعدد الخطوات (بطاقة / كاش / CliQ)
- 🔍 بحث وفلترة المنتجات
- 📱 متوافق مع الجوال بالكامل
- 🌙 تصميم داكن احترافي
- 6 فئات: هواتف، حواسيب، لوحية، كهربائي، تعليمي، إكسسوارات
- 16 منتج مع أسعار وتقييمات

## 🚀 رفع على GitHub Pages
1. أنشئ Repository جديد باسم `weebeynet`
2. ارفع الملفين: `index.html` و `README.md`
3. روح **Settings ← Pages**
4. اختار **Branch: main / root** ثم Save
5. انتظر دقيقة والرابط يكون جاهز ✅
